四个终态
DONE · DENIED · FAILED · NEEDS_REVIEW

终态含义：DONE 验收通过；DENIED 越权；FAILED 预算耗尽；NEEDS_REVIEW 验收连续 3 次失败或长期未知。

L4

代码级

外层一个动作，内层五道检查

外层：一条消息的五个出口

动作是模型返回值，不是分类器结论。每个动作都会写进 session_messages.action。

action = model.decide(session_history, workflows)

match action.kind:
    "open":    runtime.start(action.text, session=session)
    "advance": runtime.send(action.wf, action.text)
    "status":  store.workflow(action.wf)
    "ask":     return action.text          # 人回答，不猜
    "reply":   return action.text

内层：写路径五道检查

任何一道返回非 ok，执行都不会发生。顺序是刻意的：先合法，再有出处，最后才谈批准。

def dispatch(wf, call, results):
    spec = validate(call)                    # 1 契约
    check_grounding(spec, call.args, results) # 2 来源
    if "read" not in roles[actor]: return denied
    if spec.is_write:
        bound = digest(spec, call.args)      # 3 摘要
        if not is_approved(wf, bound): return wait_approval
    try:
        return execute(spec, args, idem_key(...))  # 4 幂等 5 执行
    except CommitTimeout:
        return UNKNOWN                    # 不猜、不重提
